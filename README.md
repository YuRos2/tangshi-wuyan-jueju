# 拾字成詩 · 唐詩五言絕句

一個「亂字重組」的唐詩小遊戲：隨機取《全唐詩》五言絕句一首，把二十個字打亂置於下方字庫，
玩家逐字點選、落於上方米字格，四句二十字皆與原詩相符即成局，並凝成一張可收藏的**成就卡牌**。
整體取**敦煌壁畫**的礦物顏料調：土紅、石青、石綠、雌黃、蛤粉，地仗為土牆沙色，
飾以卷草、忍冬、火焰、蓮花、飄帶與藻井紋樣；字大、格清，專為手機觸控設計。

- 引擎：**Godot 4.7.2**（GL Compatibility / WebGL2）
- 目標平台：**桌面 + 安卓手機瀏覽器（網頁版）**，豎屏 720×1280 基準自適應
- 詩庫：**3708 首**唐五言絕句（繁簡雙文、四級品相）

> 本倉庫只收錄 **Godot 工程源碼**（`scripts/` `data/` `fonts/` `audio/` `main.tscn` `project.godot`）。
> 不含任何導出產物（網頁 / 單文件 HTML / exe），也不提供在線托管與在線試玩。
> iOS / iPhone 不在支持範圍。

## 一、玩法

| 動作 | 效果 |
|---|---|
| 點字庫中的字牌 | 該字飛入當前待落的米字格 |
| 點空格 | 指定該格為下一個落字處（金框脈動者） |
| 點格中已落之字 | 退回字庫（道具所定之字不可移） |
| 二十字盡落 | 自動校勘：合者轉青、誤者震顫並退回字庫 |
| 全部相符 | 此局已成 → 展示成就卡牌 → 收下／再來一局 |

**四個系統**

1. **文氣（體力）**：上限 20，開卷耗 2，換題耗 1；每 3 分鐘自復 1 點，離線亦按真實時間結算。
2. **道具**：青玉硯（提示一字）、菱花鏡（照影三息）、清心茶（文氣 +5）、琅嬛符（天成補全）。
   以**文貝**於書坊購置；完成詩篇可得文貝（初藏新篇尤厚，逸品最豐）。
3. **成就卡牌**：每成一詩得一卡，記題目、作者、出處、全詩（**橫排四句五字、去標點**，如寫經原貌）、品相、編號、落款、
   **記憶階**與評章。卡牌可分品：**逸品**（傳世名篇）＞**神品**＞**妙品**＞**能品**。
   零失誤者鈐「一氣呵成」印；借琅嬛符者記「天授」。
   卡牌可**存為圖片**（桌面存至 `user://cards`，網頁版直接觸發下載）。
4. **記憶曲線（卡冊即溫習庫）**：每張卡都有自己的**檔期**，到期溫習就是「閃卡」。見下節。

另有 18 項成就（初開卷、百首通儒、五色雲箋、勤學不輟……），達成即賞文貝。

## 一之二、記憶曲線機制（閃卡）

**溫習不是重玩，而是閃卡**：三秒閃現一張已藏卡牌 → 自評印象 → 依記憶曲線排下次檔期。
目的是以溫習**回文氣、得文貝**，與「開卷新詩 / 書坊購物」構成閉環。

| 自評 | 檔期變化 |
|---|---|
| **記得清楚** q=3 | 記憶階 +1；下次 **1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 日** |
| **有些模糊** q=2 | 階不變，檔期 = 原檔期 × 0.6 |
| **沒記住** q=1 | 階 −1，**10 分鐘後再會** |

- **閃現時長隨記憶階遞減**：階 0 → 3.2 秒，階 7 → 2.0 秒（記得越牢，看得越快）。
- 閃現完卡牌翻為「卡背」（朱砂「記憶」印），此時憑印象自評；評完亮出卡牌作一次再認。
- **「再閃一次」**可用一次，但該張評級上限為「有些模糊」。
- **溫習免費**（不耗文氣）；只有**到期**溫習才有賞：文氣 +1~2、文貝 +2~9（含品級與記憶階加成）。
  兩者皆有**每日額度**（文氣 10／文貝 60），額滿仍可溫習但不再回賞——這條防線保證文氣經濟不會被刷穿。
- 未到期的卡可從卡牌詳覽「閃現溫習」隨意溫習：無賞、不改檔期、不耗氣。
- 一輪可連溫當日全部到期之卡（隊列式），溫畢有總結（篇數、回氣、得貝、明日到期數）。
- 新卡落地即入檔：階 0，**明日**首次溫習。開卷若重遇已藏之詩，記憶階 ≥4 者字庫摻入 5 個干擾字。
- 入口：主界面「溫習 N 篇」、卡冊「開始溫習 N」、卡牌詳覽「閃現溫習」。
- 卡冊有「待溫習／逸神妙能」篩選與三種排序，並有**未來七日到期柱圖**；縮略卡上直接顯示記憶階墨點與「待溫習 / N 日後」。
- 存檔 `ver: 2`，舊檔自動升級：已藏卡全部入檔（即刻可溫習）。

## 二、工程結構

```
project.godot            引擎配置（豎屏、canvas_items + expand、gl_compatibility、autoload）
main.tscn / scripts/main.gd      應用外殼：場景路由、彈層、浮出提示
scripts/
  core/
    palette.gd           全部配色（敦煌礦物顏料：土紅／石青／石綠／雌黃／蛤粉／四級品相）
    defs.gd              道具、成就、中文數字與落款日期
  autoload/
    ink.gd               字體、主題、樣式盒與控件工廠（全局單例，名字避開內建類 Skin）
    sfx.gd               音效池（程序生成的古意短音）
    poem_db.gd           詩庫載入、抽詩加權、繁簡取文
    game_state.gd        存檔、文氣、文貝、道具、卡牌、成就
  widgets/
    gfx.gd               敦煌紋樣：卷草藤蔓、忍冬卷角、火焰、蓮花、飛天飄帶、藻井、壁畫邊飾
    press_control.gd     可按壓控件基類（觸控／鼠標、回彈、防抖）
    mizi_cell.gd         米字格
    char_tile.gd         字牌
    card_widget.gd       成就卡牌（全幅／縮略，直繪，可任意尺寸等比渲染；含記憶階墨點）
    due_chart.gd         記憶曲線：未來七日到期柱圖
    card_viewer.gd       卡牌詳覽彈層 + 存為圖片（SubViewport 渲染）
    ink_bar.gd           文氣槽      paper_bg.gd  壁畫地仗底（藻井／飄帶／卷草邊飾）      seal.gd  土紅印
  screens/
    home_screen.gd       主界面（開卷／溫習入口）
    game_screen.gd       對局（亂字重組；重遇已藏之詩時摻干擾字）
    review_screen.gd     溫習（閃卡：三秒閃現 → 自評 → 排檔期 → 回文氣文貝）
    album_screen.gd      卡冊 + 成就   shop_screen.gd  書坊
data/
  poems.json             詩庫（每首：作者、題目、兩聯原文、簡體、品級、重字數）
  t2s_map.json           繁→簡逐字映射（介面文案轉換用）

fonts/OFL.txt            字體授權（SIL OFL 1.1，含網頁子集化的附加許可）
audio/*.wav              程序合成的音效
export_presets.cfg       Web / Windows 匯出預設
```

## 三、運行與匯出

```bash
# 編輯器
godot --path .            # 或用 Godot 4.7.2 開啟本目錄

# 匯出（需先裝 4.7.2 匯出模板）
godot --headless --export-release "Windows" build/ShiZiChengShi.exe
godot --headless --export-release "Web"     build/web/index.html
```

網頁版要點（已在 `export_presets.cfg` 中配好）：

- `variant/thread_support=false` → 使用 `web_nothreads` 模板，**不需要 COOP/COEP 響應頭**，
  任何靜態伺服器都能跑（本機 `python -m http.server` 即可）。
- `html/canvas_resize_policy=2`（自適應）+ 豎屏 viewport meta，手機瀏覽器佔滿全屏、可縮放適配。
- 已啟用 PWA：手機瀏覽器「添加到主屏幕」後可全屏獨立運行，並帶離線快取。

手機調試方式：把手機與電腦接入同一局域網，在匯出目錄起一個靜態伺服器，
手機瀏覽器訪問 `http://<電腦IP>:端口/index.html` 即可（僅安卓；iOS 不在支持範圍）。

> ⚠️ 網頁版**不能用雙擊 `index.html`（file://）的方式打開**，瀏覽器會阻止加載 wasm。
> 必須由 http(s) 提供（本機可用 `python -m http.server`）。

## 四、可調參數速查

| 想改什麼 | 位置 |
|---|---|
| 文氣上限／回復間隔／開卷與換題消耗 | `scripts/autoload/game_state.gd` 常數區 |
| 通關文貝獎勵、完美加成 | 同上 `REWARD_NEW` / `REWARD_OLD` / `PERFECT_BONUS` |
| 道具名稱、價格、說明 | `scripts/core/defs.gd` 的 `ITEMS` |
| 成就條件與獎賞 | `defs.gd` 的 `ACHIEVEMENTS` + `game_state.gd` 的 `_check_achievements()` |
| 抽詩權重（品相／是否已收藏） | `poem_db.gd` 的 `BASE_WEIGHT` 與 `pick()` |
| 記憶檔期階梯、干擾字門檻 | `game_state.gd` 的 `SRS_LADDER` / `SRS_LAPSE_SECS` / `DECOY_FROM_STAGE` / `DECOY_COUNT` |
| 溫習回賞與每日上限 | 同上 `REVIEW_STAMINA` / `REVIEW_COIN` / `REVIEW_STAMINA_CAP` / `REVIEW_COIN_CAP` |
| 閃現時長（按記憶階） | 同上 `FLASH_SECS` |
| 開卷重遇的評分 | 同上 `quality_of()`（依失誤與是否借道具） |
| 品級評定規則 | 重新生成數據時的 `build_data.py`（見下） |
| 配色、字號 | `scripts/core/palette.gd`、`scripts/autoload/ink.gd` 的 `F_*` |

## 五、數據與授權

- **詩文**：取自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT）中的
  全唐詩五言絕句全量數據（原文件 3985 首）。經篩選：僅保留「兩聯 × 五字」、
  標點規整、且字形盡在字體覆蓋範圍內的詩篇，共 **3708 首**。
  品級由「傳世名篇 → 大家名作 → 僻字奇文」綜合評定並按分位數分檔。
- **字體**：霞鶩文楷 LXGW WenKai（SIL OFL 1.1）。本項目使用其**子集**（僅遊戲用到的字形），
  許可證見 `fonts/OFL.txt`。
- **音效與圖示**：隨遊戲程序生成（正弦／噪聲合成 + Pillow 繪製），無第三方素材。

> 詩文依《全唐詩》原文（多為繁體，且部分篇目與今傳誦版本用字不同，如《靜夜思》作
> 「牀前看月光……舉頭望山月」）。介面與詩文皆可在主界面一鍵切換繁簡。

## 六、存檔

- 位置：`user://tangshi_save.json`（Windows：`%APPDATA%\Godot\app_userdata\拾字成詩\`；
  網頁版：瀏覽器 IndexedDB）。
- 內容：文氣與其時間戳、文貝、道具、卡牌（含 `stage`/`due`/`rev`/`lapse`）、成就、統計、設置，
  以及每日溫習上限計數（`review_day`/`stamina_from_review`/`coins_from_review`）與連續天數（`streak`）。
- 版本：`ver: 2`。載入舊檔（ver 1）時自動升級，已藏卡全部入檔，即刻可溫習。
- 網頁版清瀏覽器數據即會清檔，重要收藏請用「存為圖片」導出。

## 七、已知限制

- 網頁版首次載入需下載約 39 MB 的 wasm（gzip 後約 9 MB），之後由 PWA 緩存，二次進入很快。
- 桌面版未做視窗尺寸自適應以外的特別優化，建議以豎屏比例視窗遊玩。
- 詩庫品級／名篇清單為人工規則，非學術評價。
